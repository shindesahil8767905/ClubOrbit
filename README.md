# ClubOrbit — Clubs & Communities Platform (HTML & CSS)

A responsive, high-fidelity frontend prototype built with **pure HTML, CSS, and Vanilla JavaScript** — zero Node.js, zero npm, and zero dependencies required!

---

## ⚡ How to Run
Simply open **[`index.html`](file:///c:/Users/shind/OneDrive/Desktop/S/index.html)** directly in any modern web browser:
- Double-click `index.html` in your file explorer, OR
- Right click `index.html` → Open with Chrome / Edge / Firefox / Safari, OR
- Use the VS Code Live Server extension if preferred.

---

## 🌟 Included Screens & Interactive Features

### 1. Public Pages (Before Login)
- **Home (`Home`)**
  - Hero with animated orbit graphics, live stats strip (12k+ members, 340 communities).
  - Category filters (Technology, Design, Photography, Gaming, etc.).
  - Featured club cards with interactive Join & Follow toggles.
  - Trending discussion feature with instant replies link and save bookmarking.
  - Upcoming events sneak peek with direct RSVP actions.
- **Events (`Events`)**
  - Active community calendar illustration widget.
  - Filter by "All Events", "Online / Virtual", and "In Person".
  - **Event Details Modal** with full schedule agenda timeline, attendees counter, and interactive RSVP with digital confirmation pass generation.
- **About (`About`)**
  - Platform mission statement & value pillars.
  - Step-by-step "How It Works" workflow.
  - Core team member cards with avatars and bios.
- **Contact (`Contact`)**
  - Interactive contact form with automated ticket confirmation.
  - Direct support channels and trust hotline.
  - Searchable FAQ accordion with animated plus expansion.

### 2. After-Login Pages
- **Clubs (`Clubs`)**
  - **Directory**: Category chips, live search filter, and "+ Create a Club" modal.
  - **Dedicated Club Details View**: Banner art, member counter, leader welcome, community guidelines, upcoming club events.
  - **Discussions Tab**: Club-specific threads.
  - **Members Directory Tab**: Searchable roster with Admin / Moderator / Member roles.
  - **Announcements Tab**: Pinned notices broadcast by club organizers.
  - **Leader Governance**: Modals to manage member roles, remove members, and invite new members by email.
- **Discussions (`Discussions`)**
  - Feed categories (Trending, Design Talk, Milestone, Architecture, etc.).
  - Discussion composer card with instant publishing.
  - Moderator controls: Pin / Unpin posts, Delete / Remove discussions.
  - Likes counter with instant feedback.
  - **Thread Comments Modal**: Full discussion details, threaded comments with author roles, timestamps, and live reply composer.
- **Profile (`Profile`)**
  - Member profile banner with verified badge and editable bio/location.
  - Real-time stats (Clubs Joined, Events Registered, Saved Items, Followed Communities).
  - My Clubs panel with direct links and leave options.
  - My Events panel with confirmation ticket passes.
  - Chronological user activity timeline.

## 🎨 Design & Controls
- **Fixed Identical Header & Footer**: Maintained identically across every screen.
- **Public / Member Mode Toggle**: Use the badge in the top-right header to switch between "Public (Guest)" and "Member (Auth)" states at any time.
- **9:16 Mockup Frame Toggle**: Switch between full responsive web layout and the requested 9:16 laptop browser window mockup (1080×1920 preview).
